# 个人项目驾驶舱

一个面向个人产品经理的项目上下文管理 Web App 原型。第一版使用 React + TypeScript + Vite 实现中文交互界面，先用前端本地状态模拟数据流，后续可接入登录服务、服务端数据库、AI 模型和飞书机器人。

## 已实现的预览功能

- 中文登录入口
- 今日项目驾驶舱
- 项目卡片列表
- 项目详情与一日一篇项目日记
- 今日收件箱与手动归档
- AI 建议归档的交互预留
- 项目待办、截止日期、优先级、跨项目今日待办
- 搜索与状态、标签筛选
- 手动生成周/月总结的模拟流程
- 单项目和批量 Markdown 导出

## 本地运行

```bash
npm install
npm run dev
```

当前开发服务默认使用 Vite。如果 5173 端口被占用，Vite 会自动切换到下一个可用端口。
