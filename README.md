# 项目篮子

项目篮子是一个面向个人项目管理的工作台，用来集中整理项目、日记、草稿、待办、风险和总结文档。它适合同时推进多个项目的人，把分散的想法、进展和后续动作沉淀到清晰的项目上下文里。

## 产品能力

- 项目篮子：集中浏览所有项目，并按关键词、状态和标签筛选。
- 项目详情：记录项目日记，维护项目状态、标签、待办和风险。
- 草稿箱：暂存会议记录、聊天片段、想法和方案，并归档到对应项目。
- AI 总结：基于项目上下文生成结构化总结，并沉淀为总结文档。
- 总结文档：查看按项目生成的周总结、月总结和 AI 对话总结。
- Markdown 导出：支持单项目或批量导出，便于备份和二次整理。

## 本地运行

```bash
npm install
npm run dev
```

开发服务使用 Vite 启动。如果 5173 端口被占用，Vite 会自动切换到下一个可用端口。
