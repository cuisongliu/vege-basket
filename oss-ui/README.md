# OSS UI

一个用于管理项目安装包选择、操作记录和时间线文档的轻量 Web 工具。

## 功能概览

- 项目列表与项目详情管理
- 安装包市场与项目安装包选择
- 操作记录、事件和 Markdown 文档时间线
- 项目时间线 Markdown 导出

## 本地运行

```bash
npm install
npm start
```

默认本地服务地址：

```text
http://localhost:4173/
```

## 配置

运行前请通过环境变量配置服务端所需的访问凭据、存储参数和访问密码。

不要将真实密钥、内部路径、默认密码或临时下载链接提交到仓库。

## 检查

```bash
npm run check
```
