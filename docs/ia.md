# 信息架构

本文记录当前 Web 界面已经实现的信息组织、导航关系和主要用户流。界面事实以 `src/App.tsx`、`src/App.css` 和 `src/components/project-package-workbench.tsx` 为准；本文不描述 PRD 中尚未落地的能力，也不代替 API 或运维文档。

## 入口状态

应用进入可操作工作区前有三个界面状态：

| 状态 | 展示内容 | 进入下一状态的方式 |
| --- | --- | --- |
| 未登录 | 用户名与密码登录、注册、飞书登录；共享 AI 启用后密码注册必须来自有效项目邀请 | 登录或注册成功后加载工作区 |
| 工作区同步中 | 独立的同步等待页 | 当前用户和工作区数据返回后进入主界面 |
| 已登录 | 主导航、当前视图和账户菜单 | 退出登录后返回未登录状态 |

飞书 OAuth 登录结果优先从 URL fragment 读取，并兼容旧 query 参数；读取后会立即从地址栏清理登录状态和 token。项目邀请 token 仍通过 URL query 进入接受流程。

## 全局结构

已登录界面由主导航和工作区组成：

```text
工作区
├── 项目篮子
├── 当前待办
├── 通知中心
├── 草稿箱
├── Veges AI
└── 项目详情
    ├── 项目日记与待办
    └── 交付工作台
        ├── 交付事件
        ├── 事件级文档或操作
        └── 安装包组
            ├── 安装包条目
            └── 操作时间线
```

主界面不是多页面路由。五个主视图、项目详情和项目内子视图由客户端状态切换；返回关系依赖界面内的返回按钮，而不是浏览器路径。

### 主导航

桌面端主导航位于左侧，包含品牌区、五个主入口和账户菜单。通知中心入口显示未处理通知总数，计入项目邀请、指派待办、指派交付事件、明日到期待办和备注提及。

账户菜单承载当前账户信息、显示名称与密码设置、飞书账号绑定状态、每日待办推送订阅、明暗主题切换和退出登录。每日推送默认关闭，绑定飞书后可设置发送时间；系统时区固定显示为 `Asia/Shanghai`。

### 顶部栏

顶部栏显示当前视图或项目名称，并按上下文提供操作：

- 项目篮子：新建项目。
- 项目日记：进入交付工作台；项目 Owner 还可管理项目模块、成员、邀请链接和项目群通知；支持 Markdown 导出。
- 交付工作台：返回项目日记、导出时间线、向当前事件添加安装包。
- 待办详情聚焦状态：隐藏顶部栏，为详情编辑留出完整空间。

进入交付工作台时，主导航整体隐藏，工作台使用完整内容宽度。

## 主视图

### 项目篮子

项目篮子是默认视图，用于浏览和维护全部可见项目。

- 搜索覆盖项目名、简介、标签、日记、待办和总结内容。
- 可按项目状态和标签筛选。
- 项目条目显示状态、访问角色、创建时间、名称、标签和可选简介。
- 点击条目进入项目详情。
- Owner 可修改状态、重命名、编辑简介、生成周总结、导出或删除项目。
- 无项目时展示创建第一个项目的空状态。

### 当前待办

当前待办聚合未归档项目中的待办，用于跨项目处理动作项。

- 顶部指标可切换全部、未完成和已完成状态。
- 支持关键词、项目、负责人和优先级筛选。
- 结果按项目分组，项目标题可返回对应项目详情。
- 待办可直接切换完成状态；打开详情后可查看或编辑标题、详情、创建日期、截止日期、优先级、负责人和模块。
- 已完成待办显示完成时间和实际完成人，而不是仅显示一个布尔状态。
- 待办详情支持确认或驳回状态、驳回原因、备注、成员提及和图片附件。
- 无数据时区分“当前没有待办”和“没有符合筛选条件的待办”。

### 通知中心

通知中心按通知类型分组，并提供同类型数量筛选：

| 分组 | 主要信息 | 主要去向或动作 |
| --- | --- | --- |
| 项目邀请 | 项目与邀请方 | 接受、拒绝或忽略 |
| 指派给我的待办 | 项目、模块、优先级、截止日期、指派人 | 打开待办或标记已知 |
| 指派给我的交付事件 | 项目、事件类型、交付状态、指派人 | 打开项目或标记已知 |
| 明日到期 | 项目、模块、优先级 | 打开待办或忽略 |
| 备注提及我 | 待办、项目、提及人、备注摘要 | 打开待办或忽略 |

选择某类指标后仅展示该类通知；再次选择可回到全部。没有可见通知时展示与当前筛选条件对应的空状态。

### 草稿箱

草稿箱用于先捕捉、后归档未整理信息。

- 左侧或上方是快速捕捉输入区，支持成员提及；回车提交，`Shift+Enter` 换行。
- 待归档列表区分手动记录、飞书转发和 AI 分析中状态。
- 未处理条目可选择项目归档，或经确认后删除。
- 没有项目时，归档区域提示先创建项目，但仍保留删除入口。

### Veges AI

Veges AI 是统一的单一聊天界面。空白状态只保留消息输入区，不展示功能入口、提示卡片或助手选择器。总结、待办提取和对话分析都是同一段对话中的能力，不作为可见 Tab、助手模式或独立导航；模型地址、Key 和模型名仍由服务端统一配置，页面不提供个人凭据输入。

- 用户通过明确的自然语言意图触发项目总结、Markdown 待办提取或对话分析；能力识别和路由只在系统内部发生。不能明确匹配这些能力的输入按普通聊天处理，不猜测或切换工作流。
- 输入框中的 `@` 用于选择项目上下文。选择结果以独立的项目 ID 保存，并显示为可移除的上下文标签；项目名只用于展示，不用于解析权限或请求归属。
- 一段对话最多关联一个项目。更换或移除项目会清空当前消息，并使上一项目的在途响应失效，避免跨项目混合历史、响应或保存结果。
- 对话输入支持回车发送、`Shift+Enter` 换行；发送期间禁用重复提交。关联项目后的普通回复可保存为独立 AI 文档。
- 明确的项目总结意图必须同时带有通过 `@` 选中的项目上下文；系统从输入措辞识别当前上海自然日的日总结或当前周一到周日的周总结。缺少项目上下文时留在输入区提示补充 `@项目`，历史日期请求按普通聊天处理；AI 返回后直接保存为独立文档，不增加确认步骤。
- 用户在输入框中粘贴 Markdown，并明确要求提取待办时，系统直接生成候选审核。AI 推断项目、模块、负责人、截止日期、优先级、标题和详情；用户可修改和勾选候选，确认后才批量创建待办。
- 待办候选审核对话框关闭后保留当前编辑，并提供继续审核入口。
- 明确的对话分析意图会解除当前项目上下文并改变内部能力路由，不在界面中暴露“对话分析”助手或模式选择器；之后重新选择 `@项目` 会恢复项目上下文能力。
- 待办候选审核和 AI 结果产物仍可按需打开，而不作为空态功能入口。桌面端的结果产物使用侧面板，窄屏使用替换聊天区的全宽面板，不与聊天永久并排展示；产物面板提供列表、文档详情、工作区导出和展开阅读，展开阅读状态可用 `Escape` 退出。
- 没有产物时展示 AI 产物空状态；模型未配置或状态读取失败时在聊天界面统一阻断相关操作。

## 项目详情

从项目篮子、当前待办或通知进入项目后，默认落在项目日记视图。项目切换会重置当前项目内的临时选择，并按项目恢复尚未提交的待办草稿。

### 项目日记

项目日记是项目详情的主要上下文区：

- 可保存今日日记，也可为既往日期补记。
- 日期选择器标记已有日记的日期，并支持在相邻有记录日期间切换。
- 日记列表支持编辑、删除、公开/私密切换，以及标记或解除风险。
- 当前日期没有记录时显示对应空状态。
- 项目成员信息用于输入时的 `@` 提及。

### 项目待办

项目待办与日记处于同一项目上下文：

- 新建待办时可填写标题、详情、创建日期、截止日期、优先级、负责人和模块。
- 新建草稿按“用户 + 项目”保存在浏览器本地，切换项目后分别恢复。
- 待办列表支持关键词和组合条件筛选；条件可覆盖标题、模块、负责人、创建人、优先级、完成状态、确认状态、截止日期和创建日期。
- 打开待办后进入聚焦详情，查看或编辑完整字段、备注和图片；返回后恢复项目待办列表。
- 图片粘贴先显示上传中附件，完成后替换为服务端图片地址；上传失败只移除本批附件，并保留其间输入的文字和其他并发附件。
- 待办动态按时间展示创建、指派、确认、驳回、完成和重开事件，并标明操作人；日/周总结以这条事实流为主要周期依据。

### 项目配置

项目 Owner 可从顶部栏进入两个配置面板：

- 项目模块：创建或删除供待办归类的模块。
- 项目配置：按用户名邀请成员、复制邀请链接、移除成员，并配置项目飞书群通知开关和 `chat_id`。

协作成员可以查看其有权限的项目，并在项目、待办和交付事件中参与被授权的操作；Owner 专属入口不会对成员显示。

## 交付工作台

交付工作台是项目详情内的第二个信息层级，围绕“事件 → 安装包 → 操作记录”组织。

### 事件层

- 没有事件时先展示创建事件的引导空状态。
- 事件包含初始化安装或升级类型、标题、交付日期、交付人和草稿/交付中/已交付状态。
- 左侧事件列表支持切换当前事件，也可仅查看指派给当前用户的事件。
- 当前事件显示由操作及其关联待办计算出的完成进度。
- 删除事件会连同其安装包和记录一起删除，因此必须经过确认。

### 文档与操作层

- 事件可包含事件级文档或操作；安装包组下也可维护操作时间线。
- 文档编辑器使用单栏所见即所得画布，提供标题、强调、链接、列表、引用、代码和基础表格工具。代码块从工具栏菜单显式选择语言并按 Markdown fenced language 显示语法高亮；未指定或未知语言按纯文本显示，不自动猜测。链接在工具栏按钮旁的浮层中编辑，可再次点击按钮、点击外部、按 `Escape` 或使用关闭按钮退出。保存时仍以 Markdown 字符串进入现有接口。
- 操作可关联当前项目中已确认的待办，并同步维护待办完成状态和关联备注。
- 关联待办支持搜索和组合筛选；没有可关联或已选择的待办时分别显示空状态。
- 保存任一步失败时保留编辑对话框和当前输入，供用户修正或重试。

### 安装包市场

- 先选择基础包、应用包或中间件，再选择正式/测试渠道、`amd64`/`arm64` 架构和可用版本。
- 基础包只使用正式渠道。
- 详情区展示 OSS 对象、版本、大小、临时下载链接和对象 Key。
- 用户先把一个或多个对象加入待添加清单，再统一写入当前事件。
- 详情切换期间显示加载状态；没有对象、读取失败或尚未选择详情时分别显示对应状态。
- 只有最新一次查询结果可以更新详情，待添加条目的包、渠道和架构来自该详情的查询上下文。

### 时间线导出

顶部栏可导出当前项目的交付时间线。导出前先进入单栏所见即所得编辑对话框，确认后下载 Markdown 文件；空内容不能确认导出。

## 关键用户流

### 从线索沉淀到项目

```text
草稿箱快速捕捉 → 选择目标项目 → 归档 → 项目上下文更新
```

### 从项目记录到执行

```text
项目篮子 → 项目详情 → 记录日记或风险 → 新建待办 → 在项目或当前待办中跟进
```

### 从通知回到上下文

```text
通知角标 → 按类型筛选 → 打开项目或待办 → 处理内容 → 标记已知或忽略
```

### 维护交付记录

```text
项目详情 → 交付工作台 → 创建事件 → 从包市场选择对象 → 写入当前事件
→ 维护事件级或安装包级操作 → 关联待办 → 导出时间线
```

### 生成总结文档

```text
Veges AI 通过 @ 选择项目 → 输入明确的当前日/周总结意图 → 自动保存
→ 按需打开 AI 产物 → 列表或展开阅读
```

### 从 Markdown 生成待办

```text
Veges AI 粘贴 Markdown 并输入明确的待办提取意图 → AI 推断候选字段 → 用户编辑并勾选
→ 确认创建 → 待办与活动事实一次写入
```

### 订阅飞书日报

```text
账户设置 → 绑定飞书 → 开启每日推送 → 设置时间 → 保存
→ 次日收到昨日完成/重开活动与发送时的当前积压
```

## 响应式原则

- 宽屏使用固定侧栏和内容工作区；交付工作台隐藏侧栏并扩大内容区域。
- `1100px` 以下主导航改为页面顶部区域，项目详情、草稿箱、事件布局、包市场和文档编辑器改为单列；Veges AI 的产物面板按需替换聊天区，不纵向堆叠聊天与产物。
- `760px` 以下导航采用两列，搜索、筛选、表单和待办工具改为单列；项目详情的辅助面板排在主要日记内容之前。
- 桌面端依赖固定高度和内部滚动的列表，在较窄视口改为自然文档流，避免嵌套滚动。
- 对话框宽度受视口约束；所见即所得编辑器在中小屏保持单栏，工具栏自动换行，正文独立滚动。
- 按钮、筛选器和操作区在空间不足时换行或拉伸到可点击的整行宽度。

## 加载、空状态与错误

| 场景 | 当前反馈 |
| --- | --- |
| 初次加载工作区 | 独立同步等待页 |
| 后台同步或通用操作错误 | 工作区顶部同步横幅；错误状态使用错误样式 |
| 登录、注册或 OAuth 失败 | 登录面板内错误信息 |
| 项目、日记、待办、通知、总结为空 | 各视图使用与当前筛选或上下文对应的空状态文案 |
| 包市场读取中、无对象或读取失败 | 详情区分别显示加载、空结果和错误信息 |
| AI 请求中或失败 | 对话区显示整理中消息或错误信息，并阻止重复发送 |
| AI 未配置或 Markdown 无有效候选 | 工作流显示不可用状态或可重试错误；不会创建待办 |
| 待办动态读取中、为空或失败 | 项目内事实流分别显示加载、空状态和重试入口 |
| 每日推送未绑定飞书或保存失败 | 禁止开启订阅，并在账户设置内保留错误与当前时间输入 |
| 图片上传失败 | 移除失败批次的临时图片，保留最新编辑内容，并显示失败提示 |
| 交付操作或关联待办保存失败 | 保留对话框与输入，不继续执行后续更新 |

筛选造成的空结果与系统本身没有数据使用不同文案，用户可以据此判断是清空筛选还是创建内容。
