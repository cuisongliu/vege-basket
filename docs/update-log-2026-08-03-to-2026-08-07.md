# Veges 更新说明（2026 年 8 月 3 日至今）

1. 全新上线「我的待办」模块：

   - 从全局视角聚合当前用户负责推进的待办、交付事件、Bug 和项目里程碑；

   - 按逾期、今天、本周、更晚和未排期分组，并支持关键词、项目、类型、状态和创建人筛选；

   - 支持直接在列表中完成待办，点击事项可回到对应的项目、交付工作台或 Bug 工作台；

   - 将「通知中心」调整为次级入口，专门承载邀请、提及、关注和其他协作提醒。

2. 组织管理与项目治理能力升级：

   - 组织管理员可以统一查看组织内项目，并管理项目生命周期状态、健康度和风险说明；

   - 新增项目里程碑，支持设置目标日期、负责人、验收标准、执行说明和关联待办；

   - 支持里程碑创建、编辑、提交验收、确认达成、取消和重新打开，并记录协作审计事件；

   - 支持组织成员邀请、可撤销邀请链接、项目成员管理和测试空间关联；

   - 组织权限与开发工程师、测试工程师等业务角色解耦，管理员权限边界更加清晰。

3. 全新上线「周报管理」模块：

   - 组织成员可以提交个人周报，周报按照组织配置的时间窗口开放和截止；

   - 支持 AI 一键生成周报内容，并保留周期、项目和提交状态等关键信息；

   - 组织管理员可以查看成员周报、配置周报开放/截止规则，并按组织维度进行管理；

   - 新增周报深链接，打开后可以直接定位到对应组织和周报周期。

4. 交付工作台能力升级：

   - 交付事件支持草稿、交付中和已交付状态，事件文档与安装包文档均可独立维护；

   - 新增所见即所得 Markdown 编辑器，支持标题、强调、链接、列表、引用、代码块和基础表格；

   - 操作记录支持关联项目待办，并同步展示操作进度、待办状态和时间线；

   - 安装包组支持按包维护文档和操作记录，支持筛选、选择和批量关联待办；

   - 支持导出交付事件时间线，保存失败时保留当前编辑内容，方便修正后重试。

5. 交付反馈与协作通知升级：

   - 交付事件新增「交付反馈」入口，可以集中查看和提交事件评论；

   - 支持在反馈中 `@` 项目成员和组织成员，并提供成员选择和提及解析；

   - 评论作者可以编辑或删除自己的反馈，相关内容按现有敏感信息规范加密保存；

   - 被 `@` 的开发工程师会在项目篮子的通知中心收到提醒，测试工程师会在测试工作台的通知中心收到提醒；

   - 测试工作台新增与项目篮子一致的铃铛和红点通知入口，通知内容保持原有结构。

6. 测试工作台与 Bug 流程优化：

   - 用例、测试计划和 Bug 的协作关系更加明确，失败用例可以携带环境、步骤和预期结果创建 Bug；

   - Bug 列表新增组合筛选能力，支持按标题、编号、状态、负责人、测试对象、计划和关联信息筛选；

   - Bug 创建人可以在提交后继续编辑 Bug 详情；

   - 开发工程师只能推进自己负责的 Bug，新增修复中、待验证、驳回等状态流转和处理评论；

   - Bug 驳回后会向创建人发送私有通知，测试工程师可以继续确认、分派、验证和关闭 Bug；

   - 测试对象、测试计划和用例的创建人权限边界进一步收紧，删除和编辑操作更加安全。

7. 全新上线 Bug 分享能力：

   - 支持从测试工作台和 Bug 工作台生成可撤销的 Bug 分享链接；

   - 未登录用户打开链接即可查看 Bug 的基本信息、复现步骤、预期结果和实际结果；

   - 只有登录后才能发表评论，非 Bug 负责人登录后仅允许评论；

   - Bug 负责人登录后会直接进入对应 Bug 工作台，并沿用原有可操作范围；

   - 分享链接使用一次性令牌和有效期控制，服务端只保存令牌摘要，不暴露内部身份和对象存储地址。

8. 镜像同步与安装包市场升级：

   - 新增镜像同步工作流，可查看 GitHub Actions 的 Run、Job 和 Step 进度；

   - 支持筛选同步状态、查看成功产物，并复制 OSS 下载地址；

   - 对 GitHub dispatch 状态不确定的情况增加恢复和重试处理，避免重复触发工作流；

   - 安装包市场支持其他分支的 CI 包规则，并完善版本、架构、渠道和对象存储路径校验。

9. 全新上线「更新日志」模块：

   - 账户菜单新增更新日志入口，所有登录用户均可查看 Veges 的产品更新；

   - 更新日志采用文章列表形式，点击条目即可展开 Markdown 详情；

   - 系统管理员可以新增和编辑更新日志，标题、版本号和正文均加密存储；

   - 编辑器自适应占满可用屏幕，支持稳定编辑焦点，避免多余的页面纵向滚动；

   - 更新日志列表和编辑页面统一使用工作台顶栏布局，标题与操作按钮保持同一行。

10. 工程与交付稳定性提升：

   - 新增 Pull Request 镜像构建和主分支镜像发布流程，统一 Docker 构建与发布权限；

   - 完善数据库连接池、事务锁和并发写入处理，降低协作场景下的状态竞争风险；

   - Markdown 文档预览、链接校验、编辑器恢复和跨页面状态恢复逻辑得到统一处理；

   - 增加覆盖通知策略、组织权限、Bug 流程、交付评论、镜像同步和周报规则的自动化测试。
