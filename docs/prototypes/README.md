# Veges 企业工时原型

当前版本：2026-09-22 **V5**。以本版为准，V1 至 V4 仅作历史对照。

- [打开可点击 HTML 原型](worktime-v5.html)
- [查看 20 张桌面 / 移动高保真截图](worktime-v5-gallery.html)
- [最新规则、权限计划与验证说明](worktime-v5-design.md)

成员的企业工时导航只保留「我的工时」，其中包含「工时记录 / 工时统计」两个 Tab。统计、趋势、项目明细和导出始终只有本人数据，管理员进入「我的工时」也不例外。记录工时先选企业项目，再选本人负责的进行中任务，切换项目清空原任务。

组织「工时统计」及项目内第四个「项目工时」Tab 仅组织管理员可见。成员项目页保留项目待办、项目日记、交付工作台三个 Tab，项目篮子也隐藏项目工时入口。

企业项目与企业待办仅组织管理员创建，新待办预估必填。任务仍由真实创建人验收，没有可选验收人；记录工时不触发独立审核，提交任务后一起确认成果与工时。个人项目完全不改、不加工时；测试工作台保持现状。

浏览器直接打开 HTML，无需启动服务。默认展示开发成员林知远的个人统计；侧栏底部可切换演示身份。推荐走查：本人统计 → 点击项目看本人记录 → 记录工时（项目 → 任务）→ 切换管理员对比两层统计与项目第四 Tab。

所有操作仅在内存中，刷新恢复。项目与人员是虚构样例，日期固定 2026-09-22。原型使用本目录共享 CSS、V5 脚本、本地 Lucide 和仓库 favicon，保持目录结构即可运行。截图宽度为桌面 1440px / 移动 375px，弹窗为视口截图，其他页面为全页截图。

V5 原型是本次正式业务接入的交互基准；生产代码仍由服务端执行权限、数据隔离、事务和数据库约束，原型中的角色切换仅用于演示。
