# Veges 更新说明（2026 年 8 月 28 日）

1. 组织范围一致性修复：

   - Bug 工作台现在只显示当前组织下测试空间中的 Bug 和版本；读取、轮询、状态流转、转移和评论操作均会在服务端校验当前组织成员关系与测试空间归属；

   - 我的待办、待办角标与项目筛选同步使用当前组织或“个人项目”上下文，待办、交付事件、Bug 和里程碑不会跨组织混合展示；

   - 负责人从 Bug 分享链接回到 Veges 时，会恢复该 Bug 的组织上下文，避免跳转到其他组织的空工作台。

2. 个人项目导航整理：

   - 选择“个人项目”后，侧栏只显示项目篮子、我的待办、草稿箱和 Veges AI；

   - 周报管理、Bug 工作台、测试工作台、安装包市场、镜像同步和组织管理在个人项目上下文中隐藏，减少与组织协作无关的入口。

3. 回归保障与文档：

   - 新增组织上下文解析、My Work 范围、Bug 工作台 API 范围和个人项目导航的自动化回归检查；

   - 更新接口参考、信息架构和 Bug 分享边界说明。
