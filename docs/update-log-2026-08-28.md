# Veges 更新说明（2026 年 8 月 28 日）

1. 组织范围一致性修复：

   - Bug 工作台现在只显示当前组织下测试空间中的 Bug 和版本；读取、轮询、状态流转、转移和评论操作均会在服务端校验当前组织成员关系与测试空间归属；

   - 我的待办、待办角标与项目筛选同步使用当前组织或“个人项目”上下文，待办、交付事件、Bug 和里程碑不会跨组织混合展示；

   - 负责人从 Bug 分享链接回到 Veges 时，会恢复该 Bug 的组织上下文，避免跳转到其他组织的空工作台。

2. 个人项目导航整理：

   - 选择“个人项目”后，侧栏只显示项目篮子、我的待办、草稿箱和 Veges AI；

   - 周报管理、Bug 工作台、测试工作台、安装包市场、镜像同步和组织管理在个人项目上下文中隐藏，减少与组织协作无关的入口。

3. 回归保障与文档：

   - 新增组织上下文解析、My Work 范围、Bug 工作台 API 范围和个人项目导航的自动化回归检查；

   - 更新接口参考、信息架构和 Bug 分享边界说明。

4. 周报组织联动与个人入口边界：

   - 组织上下文下的日常工作只保留项目篮子、我的待办和周报管理；草稿箱与 Veges AI 仅在个人项目上下文显示，切入组织时若正停留在上述个人入口会返回项目篮子；

   - 周报管理不再显示重复的顶部组织选择器：主界面直接继承侧栏组织上下文，测试工作台直接继承当前测试空间的归属组织；切换任一上游上下文前会保存当前周报草稿；

   - 周报深链接会先校验目标组织仍可访问，再同步侧栏组织并打开指定周次，失效或无权访问的链接不会回退展示其他组织的周报。

5. 测试空间周报上下文：

   - 测试工作台从当前测试空间设置中读取组织归属，因此不再需要周报右上角的组织切换；

   - 切换到不同组织的测试空间时，系统先保存正在编辑的周报草稿；保存失败时保持当前测试空间与周报不变；

   - 未关联组织的测试空间显示明确空状态，且不会默认加载其他组织的周报。
